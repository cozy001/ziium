# ziium — 한 해의 열매 카드

`index.html`은 정적 웹앱으로 동작합니다. GitHub Pages를 활성화하면 배포할 수 있습니다.

## 배포

1. Repository **Settings → Pages**로 이동합니다.
2. **Deploy from a branch**를 선택하고 `main` / `/ (root)`를 저장합니다.
3. `ziium.fruit` 도메인을 사용하려면 해당 도메인의 DNS에서 GitHub Pages가 안내하는 레코드를 설정하고, Pages의 Custom domain에 `ziium.fruit`를 입력합니다.

`CNAME` 파일은 이미 추가되어 있습니다. 도메인을 소유하고 있지 않거나 `.fruit`가 등록 가능한 도메인이 아니라면 먼저 도메인 등록/DNS 설정이 필요합니다.
